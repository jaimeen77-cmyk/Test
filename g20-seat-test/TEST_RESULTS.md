**Seat Test 0.1.0 검증 기록**

2026-11-11. 실행 환경: Linux, Node.js 24.22.1, Python 3. 차량 연결 없이 수행하는 로컬 검사입니다.

`node test/test.js`: 14개 검사 통과, 종료 코드 0.

- 시작·조회에서 이동 요청이 발생하지 않음.
- 미확인 기어, 0이 아닌 속도, 화면 포커스 부재, 미지원 축, 기존 작업 중 이동 차단.
- 한 번의 확인으로 조수석 SLV 단일 명령만 전송하고 예약된 STOP을 세 번 시도함.
- 이동 직전 P단이 변경되면 차단.
- 차량 데이터 응답 대기 중 누른 STOP이 뒤늦은 이동 요청을 취소함.
- 화면 이탈 시 STOP 요청과 확인 해제.
- 모든 STOP 전송 실패 후 앱 세션의 추가 이동 잠금.
- 이동 전송 오류에도 STOP 시도.
- 오래된 차량·서비스 응답으로 이동하지 않음.
- 서비스 응답 구조가 불명확하면 차단하고 불필요한 개인정보를 보고서에서 제외함.
- 기존 자동 승하차 또는 복귀 대기 시 이동 차단.
- SOME/IP getter 값에서 P와 N_OR_P를 구분하고 무효 속도 값 거부.
- 실제 로컬 Unix 소켓에서 분할 응답·잘못된 JSON 처리 및 명령 범위 제한.
- 가짜 SDK로 네이티브 화면 초기화·엔트리 매핑·이동 버튼 기본 잠금·포커스 처리·보고서 저장 검증.

`python3 test/package_check.py`: USB 카탈로그의 SHA256·파일 크기, OAP 아카이브 구조, RHMI XML/JSON, 한국어 리소스, 이동 버튼 기본 비활성화, 차량 인터페이스 읽기 권한, 라이선스 고지 검사 통과.

Python 빌드 파일과 JavaScript 런타임 파일의 구문 검사도 통과했습니다. Node 8에서 직접 실행한 결과는 아닙니다.

실제 BMW SDK, MGU Store 설치, 차량의 Node 8 런타임, SOME/IP 네이티브 바인딩, HMI 입력 이벤트, Comfort 서비스와 실제 시트의 조합은 이 환경에서 검증할 수 없습니다. 패키지에는 SDK를 포함하지 않습니다. 차량 시험 결과를 주장하지 않습니다.
